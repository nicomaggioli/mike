# Michael Gold Maggioli · Freelance Data Engineer

Portfolio site for Michael Gold Maggioli, a freelance data engineer in Greater Boston.

**Live:** https://nicomaggioli.github.io/mike/

- `index.html` is the main site, styled like a code-hosting profile page.
- `vscode.html` is an alternate version styled like a code editor.

Both are single self-contained HTML files with the images embedded.

## Editing

1. Edit the source in `src/` (contact details, prices and services are in the `CONFIG` and `OFFERS` blocks at the top of each file's script).
2. Rebuild: `python3 build.py`
3. Commit and push. GitHub Pages republishes automatically.
